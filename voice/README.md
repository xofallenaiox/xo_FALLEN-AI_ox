# FALLEN Voice

FALLEN uses a private local voice sample as a reference for selecting/configuring a compatible female TTS voice.

## Privacy

The uploaded voice sample is intentionally kept out of Git history and source control. Store it locally only.

## Direction

Preferred production behavior:
- warm, intelligent female assistant voice
- clear futuristic delivery
- moderate speaking pace
- restrained expressiveness
- automatic playback after completed AI responses
- keep voice state synchronized with the FALLEN core animation

The local sample should be used as a voice-reference asset, not committed to this repository.
